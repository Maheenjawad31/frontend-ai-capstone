# AI Workflow Audit

## Overview

This document maps my recurring weekly tasks and identifies where AI can help, where human judgment is required, and where tasks can be automated.

## Weekly Task Audit

| Task | Classification | Rationale |

|---|---|---|

| Learning React and frontend concepts | Collaborate with AI | AI helps explain concepts, provide examples, and answer questions, while I verify my understanding. |

| Building coding projects | Delegate to AI with review | AI can help generate code and solutions, but I review, test, and improve the output. |

| Debugging frontend issues | Collaborate with AI | AI helps identify possible causes and solutions, but I verify the final fix. |

| Creating React components and UI features | Delegate to AI with review | AI can speed up implementation, but I check code quality and requirements. |

| Reading technical documentation | Collaborate with AI | AI helps summarize complex information, but I confirm important details. |

| Planning project structure | Collaborate with AI | AI provides suggestions, but I make the final architecture decisions. |

| Writing Git commits and documentation | Delegate to AI with review | AI helps create drafts, but I ensure they accurately represent my work. |

| Reviewing AI-generated code | Just me | Final quality decisions require my own judgment and responsibility. |

| Choosing learning goals and career direction | Just me | Personal and career decisions should be based on my own goals. |

| Practicing programming problems | Collaborate with AI | AI can provide hints and explanations, but I need to understand the solution. |

| Completing assignments and reports | Delegate to AI with review | AI can help organize ideas and improve writing, but I verify the final content. |

| Managing work and internship tasks | Collaborate with AI | AI can help organize tasks and planning, while I control priorities and decisions. |

## Three Target Tasks for Future AI Workflows

### 1. Learning Frontend Technologies

Success means:

- I understand the concept.

- I can explain it in my own words.

- I can create a working example.

### 2. Debugging Code

Success means:

- The issue is identified.

- The solution is explained.

- The fix works correctly.

### 3. Building Features with AI Assistance

Success means:

- I provide clear requirements.

- AI output is reviewed and tested.

- The completed feature meets the requirements.

## AI Workflow Principles

AI should support my work by improving speed and understanding. I will not blindly accept AI output. Every generated result should be reviewed, tested, and improved before use.
