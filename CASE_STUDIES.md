# Case Study: AI-Assisted Settings Form Workflow

## Problem

The internship assignment required me to compare a vague AI workflow with a precise AI workflow while building the same frontend feature. I needed to show how the quality of AI output changes when requirements, constraints, and verification steps are clearly defined.

## What I Did

I built a settings form in a Next.js and TypeScript project. In the first branch, I used a vague prompt and let the AI decide the structure. In the second branch, I provided detailed requirements for validation, accessibility, controlled inputs, reusable components, and verification. I manually tested both versions and reviewed the generated code before accepting it.

## Outcome

The precise workflow produced a more reliable implementation with TypeScript types, client-side validation, accessibility improvements, and a clearer project structure. The comparison helped me understand that AI works best when it receives clear instructions and when the developer reviews and tests the output.
