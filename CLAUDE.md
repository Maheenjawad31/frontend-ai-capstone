## Project

Frontend AI Capstone for FlyRank Frontend AI Engineering Internship.

## Tech Stack

- React
- Next.js
- TypeScript
- Tailwind CSS
- Node.js

## Coding Conventions

- Use TypeScript where possible.
- Keep components small and reusable.
- Follow Conventional Commits.
- Use AI to assist with coding, but review generated code.

## Project Rules Learned

- Forms must use controlled React inputs with TypeScript types. All user input should have clear validation rules before being accepted.

- All UI components must consider accessibility. Form fields require proper labels, and validation errors should be clearly connected to the related field.

- Shared types and reusable logic should be separated from components. Store shared TypeScript types in dedicated folders such as `types/` to keep the project organized.
